# 08 — Roadmap

Découpage en lots qui **fonctionnent** à chaque étape. À chaque fin de lot, l'appli est
utilisable en vrai au bar — pas de tunnel de trois mois.

## Lot 0 — Fondations (½ journée sur le Mac)
- Réparer Tailwind v4 (configs actuellement dans des dossiers, syntaxe CSS v3).
- Réorganiser le repo (app tournoi / app staff), mettre en place le routage.
- Nouveau projet Firebase, Firestore + Auth + Storage, règles de sécurité de base.
- Squelette PWA (manifeste, icône, installation sur écran d'accueil), thème du doc 05.
- Firebase Hosting + déploiement automatique par GitHub Actions.

## Lot 1 — Le dashboard et le pointage
- Connexion, gestion des comptes, rôles.
- **Dashboard personnel** (l'écran vitrine du projet).
- **Pointage** arrivée/pause/sortie + feuille d'heures + validation responsable.
- Fiche personnelle (profil + contrat + documents).
→ *À ce stade, tu peux déjà remplacer le cahier des heures.*

## Lot 2 — Planning
- Grille équipe, modèles de semaine, publication, notifications.
- Disponibilités, congés, échanges de shifts, alertes de conflit.
→ *Le planning WhatsApp disparaît.*

## Lot 3 — Tâches & recettes
- Checklists ouverture/fermeture avec photos et blocage.
- Saisie des recettes journalières, écarts de caisse, graphs de CA.
→ *L'ouverture et la fermeture deviennent traçables, le CA est suivi au jour le jour.*

## Lot 4 — Stocks
- Catalogue, inventaire mobile, mouvements, alertes de rupture.
- Commandes fournisseurs, coût matière.

## Lot 5 — Pilotage & confort
- Tableau de bord gérant multi-bars, exports paie/compta.
- Annonces avec accusé de lecture, base de connaissances/cocktails.
- HACCP (températures), incidents, pourboires.

## Ordre de priorité assumé
Si le temps manque, l'ordre à respecter est : **pointage → planning → checklists → recettes → stocks**.
C'est l'ordre du gain de temps quotidien réel pour toi et pour l'équipe.
